# Vibe & Aesthetic Manifesto (vibe.md)

**Project:** Manraj Chauhan 3D Portfolio (`manrajchauhan.com`)  
**Design Soul:** Cyber-Brutalist 3D Studio Aesthetic (Inspired by [basement.studio](https://basement.studio/))  

---

## 1. The Vibe in One Sentence
> "A dark-mode, high-octane, spatial WebGL playground that feels less like a standard web page and more like an interactive high-end digital design studio engine."

---

## 2. Core Vibe Pillars

### 2.1 Unapologetic Dark Brutalism
- **Deep Obsidian canvas (`#050505`)** that consumes light and makes 3D chrome reflections pop with metallic sharpness.
- **Massive, aggressive display headings (`Space Grotesk 800`)** that command attention and span the entire screen width.
- **Mono spec tags (`JetBrains Mono`)** like `[SYS_ONLINE]`, `[COORD: 45.12, -122.67]`, `[FPS: 60]` that give the site a tactile, technical control-panel feel.

### 2.2 Kinetic Spatial Depth
- Floating 3D geometries, metallic chrome badges, and transmission glass objects that react dynamically to pointer movements.
- Seamless embedding of live HTML text cards into 3D world space using `@react-three/drei`'s `<Html>` with 3D matrix transforms and occlusion fading.
- Camera parallax that tilts smoothly as the user glides across the page.

### 2.3 Electric Accent Sparks
- Stark monochrome contrast interrupted by intentional, high-voltage neon highlights:
  - **Electric Acid Lime (`#CCFF00`)** for primary interactive states, cursor focus, and active tags.
  - **Cyber Orange (`#FF4D00`)** for secondary alerts, live status indicators, and hover glows.
  - **Hyper Cyan (`#00F0FF`)** for subtle ambient post-processing blooms.

### 2.4 Tactile Micro-Interactions & Inertia Motion
- **Lenis Inertia Scroll:** Smooth, heavy scrolling feel where elements float into position with natural momentum.
- **Magnetic Mouse Cursor:** Pointer stretches towards interactive meshes and buttons like a gravitational magnet.
- **Cinematic Noise Filter:** A faint SVG noise texture over the viewport preventing flat banding and adding rich digital film grain.
- **Audio Feedback (Optional):** Subtle, satisfying click and hover sound design for maximum physical feedback.

---

## 3. The "Anti-Bland" Principles
1. **NO Default Generic Layouts:** Every section must feel bespoke, dynamic, and spatially aware.
2. **NO Static Content:** Text, images, and 3D objects move, respond, or glow on interaction.
3. **NO Dull Color Palettes:** High contrast, deep pitch darks, chrome physics, and neon pops only.
4. **NO Performance Sacrifices:** Buttery smoothness (60 FPS) is non-negotiable; aesthetic flair must be paired with performance tuning.
